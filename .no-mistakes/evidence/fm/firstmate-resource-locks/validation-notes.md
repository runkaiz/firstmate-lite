# Resource-lock live validation

The real `bin/fm-resource-lock.sh` and `bin/fm-brief.sh` ran against disposable homes and a private runtime directory under the gate worktree. `resource-lock-live.log` records actual command output, waits, releases, generated instructions, and negative cases. The clock seam selected daytime and overnight admission rules; all holders were real kernel flock holders. `drive.py` preserves the exact manual driver.

A real Claude print-mode primary ran `spawn-scenario.sh` on the marked disposable home `l`, using its private `fm-lab` tmux socket with 140-column by 40-row panes. Three workers each returned authenticated model output. Their real print-mode commands used the supported raw-command launch interface (`env ... claude -p ...`), so the metadata records `harness=env`; this proves the shared admission path rather than the standard Claude adapter. The finished commands kept their panes alive with `sleep` to represent idle workers. Capacity 1 did not block the third worker, and a malformed retired declaration did not block the second. Both configurations were checked for unchanged bytes. No Herdr session was used. `uncapped-spawn-live.log` preserves records and pane output.

Targeted baseline checks: `tests/fm-resource-lock.test.sh`, `tests/fm-project-capacity.test.sh`, and `tests/fm-brief.test.sh`. The first scaffold run used a worktree-local TMPDIR; its shell-safety test embeds that absolute path in a Git branch name, where the `.no-mistakes` component makes the fixture ref invalid. Re-running with the test toolchain's normal `/tmp` location passed. The first live-dispatch setup placed the native-copy root inside the lab home and was correctly refused; moving it to a sibling directory inside the worktree allowed the scenario to pass. Neither setup correction changed tracked source.

All three disposable tasks were removed with the real `fm-teardown.sh` before the private tmux server and lab directories were removed. Logs and exact driver scripts are retained here. No repository source was changed. This is a CLI change, so the product evidence consists of CLI transcripts and generated Markdown rather than screenshots.
